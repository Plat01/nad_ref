# Надеждик

Локальная адаптация главной [Crency](https://crency.agency/) на русском языке: фирменные цвета, пингвин-маскот, смысловые иконки и шесть направлений детского развития.

## Запуск

Нужны Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. По умолчанию это http://localhost:5173/nad_ref/.

```sh
npm run build
npm run preview
```

Готовые статические файлы находятся в `dist/`. Разметка формируется при сборке, поэтому текст и направления доступны без JavaScript. Шрифты, графика и библиотеки загружаются локально.

## Проверка

```sh
npm test
```

Команда собирает production-версию, запускает временный сервер на свободном локальном порту и проверяет её через Playwright в установленном Google Chrome. После проверки браузер и временный сервер закрываются.

Проверяются ширины 1440, 768 и 390 px, меню и форма, все шесть направлений, клавиатура, возврат фокуса, валидация, выбор следующего шага, уменьшенное движение, чтение без JavaScript и вертикальный жест в мобильном Chromium. Снимки сохраняются в `.impeccable/review/`, результаты — в `docs/research/verification.json`.

## Устройство проекта

- `src/content.ts` — единый каталог направлений, содержание карточек и списка формы.
- `src/render.ts` — статическая разметка; Vite вставляет её в HTML через `transformIndexHtml`.
- `src/motion.ts` — сцены GSAP, Lenis, настольный веер и мобильная книга.
- `src/ui.ts` — диалоги, навигация, форма и настройки движения.
- `src/style.css` — палитра, локальные шрифты и адаптивные композиции.
- `public/assets/` — используемые копии материалов из исходного `assets/`.
- `docs/research/crency/` — исходные HTML/CSS/JS референса для сверки; эти файлы не входят в сайт.

Описание продукта — в `PRODUCT.md`, актуальная система оформления — в `DESIGN.md` и `.impeccable/design.json`.

## Форма и движение

Форма демонстрационная: проверяет имя и телефон, показывает результат проверки и не отправляет данные. При закрытии ввод сбрасывается. Единственное локально сохраняемое значение — интенсивность движения (`nadezhdik-motion`).

Системная настройка уменьшенного движения учитывается при первом посещении. Ручной режим «Спокойнее» показывает все направления в статическом списке. Настройки можно снова открыть из подвала.

Палитра закреплена пользователем без тёмного текста. Ограничение контраста небольших подписей документировано в `DESIGN.md`; соответствие WCAG AA для мелкого текста не заявляется.

## Публикация

Сайт: https://plat01.github.io/nad_ref/.

Push в `main` запускает `.github/workflows/pages.yml`: Node.js 22, `npm ci`, production-сборка и публикация `dist` в GitHub Pages. Базовый путь `/nad_ref/` задан в `vite.config.ts` и используется при локальной браузерной проверке.
